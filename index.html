Independence by Design

Build a Claude review that is really a second opinion

Choose the setup your work needs. Build the four kinds of reviewer agent for your case. Keep a record of what each review found.

Which setup does this work need?

Answer three questions about one piece of work. If none is true, one chat is enough. All three true means separate Projects.

Build your reviewer agents

These are the instructions from the session demo runs. Add your case and each agent updates. Paste each one into its own Claude Project, or download it as a Claude Code subagent.

Run them in this order. Each one sees only what it needs.

Your working chat→Challenger+Verifier→Role reviewers→Chair→You sign

Before each review

  • Use a new chat inside the agent's Project. Do not reuse the working chat.
  • Paste the decision and the evidence. Do not paste the history, the drafts or the team's framing.
  • Check Memory. A new chat isolates history, but Memory can still carry context in. Use Incognito or turn Memory off for the review.
  • For the highest stakes, use a fresh Project per case, so project memory from earlier cases does not carry in.
  • Give the Chair the reviews with the names removed.

Review log

Log each review you run. Over time, you see which work needed an independent review. Entries stay in this browser only.
